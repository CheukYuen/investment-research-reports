# IMA 文件夹问答 · 兜漏复核指引与校准记录

> v1.0 · 2026-07-11。定位：rank-ai（标题两轮排序）是主路径；IMA 文件夹问答**只做单日粒度的兜漏复核**，专门抓"标题看不出内容"导致的漏网。IMA 的输出是候选清单，须人工复核后才能动 queue，**永远不能替代排序**。

---

## §1 为什么不能用 IMA 替代 rank-ai（2026-07-11 校准实录）

对 `7月/7.11` 文件夹（51 份）同时运行 rank-ai 快照（`manifests/ai-ranked-queue-20260711.jsonl`）与 IMA 全量分类 prompt，逐份对账：

| | rank-ai（标题排序） | IMA 文件夹问答 |
|---|---|---|
| P0/P1 判定数 | 10 | 18 |
| 漏掉该入选的 | **1**：伯恩斯坦-联发科 Q2 营收（标题是普通业绩点评，正文含 ASIC/TPU 与预测表） | **2**：花旗-东方电气（queue P0）、高盛-屹唐（queue P1）；且总数数成 50/51 |
| 假阳性 | 0 | **9**：市场周报、资金流向、SpaceX、航天等，均为"正文提及一句/一张图"即入选 |
| 输出形态 | 版本化 jsonl，score/rank 机器可读 | 聊天文本，需人工核对，文件名可能编造 |

三条结论：

1. **IMA 问答是 RAG 检索，不是遍历。**"逐份不遗漏"的承诺不可信（漏 2 份 + 总数数错）。文件夹越大覆盖越差——**禁止在月份层级问**，只在单日文件夹（≤60 份）使用。
2. **差异的主因是判定标准，不是读没读正文。**"正文提及 AI 基建"≠"研究主体是 AI 基建"；策略周报几乎篇篇提 AI，按"提及即入选"必然爆仓。Prompt 必须按"研究主体"写（见 §3）。
3. **标题过滤的实测精度好于预期**：51 份只漏 1 份边缘候选。担心"仅凭文件名过滤不行"在本次实证中不成立；rank-ai 维持主路径地位。

漏网的那份联发科：服务 ASIC/影子节点，不在光互连 thesis 受控词表内，按"不要因为顺便而买"原则未自动升级，留人工裁决。

## §2 使用规则（每次照做）

1. **只在单日文件夹用**（≤60 份），不在月份层级问。
2. **只对 rank-ai 判 P2/P3 的部分兜漏**——P0/P1 已在下载路径内，重复问浪费。
3. **结果当下限用**：IMA 不保证遍历（2026-07-11 实测漏 2 份），入选表格是"兜到的"，不是"全部相关的"。不要基于"IMA 没报"下任何结论。
4. **文件名先验证再采用**：IMA 返回的文件名和 `manifests/index.jsonl` 对一遍（可能编造或拼错）。
5. **提名升级须人工过四问**（能证伪吗 / 领先吗 / 稀缺吗 / 是事实吗，见 copilot 仓库 `docs/DATA_SOURCING.md` §1），通过后手动调整 queue 优先级，不自动写入。

## §3 Prompt A：全量分类（单日文件夹兜漏用）

```
逐份检查当前文件夹全部 PDF。判定依据是报告的【研究主体】——标题所指的公司/行业
或占报告一半以上篇幅的内容——而不是正文是否提及某个词。

【入选】研究主体属于 AI 基础设施：hyperscaler/AIDC 资本开支、AI服务器、GPU/ASIC、
HBM/存储芯片、先进封装、光模块/光互连/CPO/硅光、数据中心网络、数据中心电力与液冷、
半导体设备与材料。

【不入选——即使正文提及上述内容】：
1. 市场策略周报、资金流向、宏观、跨行业策略类报告；
2. AI 应用/大模型/软件公司（除非主体是算力采购或数据中心建设）；
3. 航天、卫星、国防（除非主体是在轨算力）。

唯一例外：以上类型若含有该机构自己给出的分年度预测数字表，可入选并标注"仅数据表"。
数字表须覆盖以下至少一项：
- hyperscaler capex（微软/谷歌/亚马逊/Meta 分家数字）
- AI 服务器出货量（分年度或分季度）
- GPU/ASIC 出货量，或云厂商自研芯片放量节奏
- 800G/1.6T 光模块出货量、ASP 及降幅
- CPO/硅光渗透率或量产时间表
- HBM 供需缺口、价格
- DRAM/NAND 合约价或现货价走势预测
- CoWoS/先进封装产能
- 液冷渗透率、数据中心电力需求
- 光模块/AI 硬件龙头的份额与毛利率预测

输出入选表格：文件名原样 | P0/P1（拿不准写"?"） | 研究主体（一句话） | 分年度预测数字表：有(写表名)/无
```

> 注意：不输出未入选清单，就没有遍历核对——IMA 问答是检索式的，会静默漏文件（2026-07-11 实测漏 2 份）。因此把入选表格当作**兜漏的下限，不是全集**：它兜到的是净赚，没兜到的文件仍在 rank-ai queue 里按标题评级，不会丢。

## §4 Prompt B：按指标反查（光互连 thesis 定点挖数字）

窄问题的检索召回比"全量分类"可靠，且答案本身就是共识数据点线索（机构、数字、章节）。按需逐条问：

```
当前文件夹哪些报告给出了 800G 或 1.6T 光模块出货量或 ASP 的具体分年度数字预测？
列出文件名、数字所在章节/表格名，并摘录关键数字。
```

```
哪些报告讨论了 CPO（共封装光学）或硅光的渗透率、量产时间表？列出文件名和相关原文。
```

```
哪些报告包含微软/谷歌/亚马逊/Meta 任一家资本开支（capex）的指引、预测或修正？
列出文件名和具体数字。
```

```
哪些报告给出了中际旭创、新易盛、天孚通信等光模块公司的出货量、份额或毛利率预测？
列出文件名。
```
